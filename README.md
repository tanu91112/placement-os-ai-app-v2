# 🚀 PlacementOS AI

## ✨ Tagline
An autonomous multi-agent AI operating system for placement preparation.

---

# 📌 Overview
PlacementOS AI is a futuristic AI-powered career preparation platform that simulates an intelligent multi-agent system to guide students through placements.

It combines:
- Resume Intelligence
- AI Mock Interviews
- Career Analytics Dashboard

The system feels like a real AI startup product where multiple AI agents collaborate to analyze, interview, evaluate, and guide users toward job readiness.

---

# 🧠 What I Built
- Built a full-stack AI web application using **Next.js, TypeScript, Tailwind CSS**
- Integrated **Gemini API** for AI resume analysis and interview generation
- Designed a **multi-agent system simulation**
- Created futuristic UI with **glassmorphism + animations**
- Built AI mock interview system with dynamic evaluation
- Developed analytics dashboard with readiness scoring
